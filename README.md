BRAWL ARENA characters.json 方式

アップロード先: GitHub リポジトリのルート（game.html と同じ階層）

characters.json が全モード共通のキャラ情報です。現在は既存キャラ「テレポーター」を初期キャラとして登録しています。

新キャラは characters 配列にオブジェクトを追加し、defaultCharacterId を切り替えると初期キャラを変更できます。

注意: 今回は既存のゲームロジックを壊さないよう、共通データ読み込みの土台とテレポーターの基本性能を接続しています。各キャラ固有の攻撃・必殺技の完全な差し替えは、能力タイプごとの処理追加が必要です。
